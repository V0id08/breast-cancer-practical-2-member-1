# Breast Cancer Classification

This project demonstrates Git version control for a machine-learning classification project.

Dataset:
Wisconsin Diagnostic Breast Cancer dataset

Tasks:
Git initialization, commits, branches and GitHub.

## Run the program

From the project folder in Git Bash, create and activate a virtual environment and install scikit-learn:

```bash
py -m venv .venv
source .venv/Scripts/activate
pip install scikit-learn
```

Run the classification program:

```bash
python breast_cancer_classification.py
```
